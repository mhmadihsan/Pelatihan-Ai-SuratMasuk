# 00 Ringkasan Eksekutif — SIMasuk
Status: FINAL

SIMasuk adalah aplikasi web internal untuk administrasi **surat masuk**: pencatatan, nomor agenda otomatis, pencarian, buku agenda, dan laporan per periode (cetak A4 + ekspor CSV). Proyek greenfield; dibangun dengan PHP 8 native, MySQL, dan Tailwind CSS; dikembangkan dan dijalankan di macOS.
